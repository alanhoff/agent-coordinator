# Contributing

Contributions are welcome through focused issues and pull requests. The runtime has one owner for each
core invariant: `src/coordinator/state`, `routing`, and thin `cli` adapters. Preserve those boundaries
and the no-project-footprint contract.

## Development

Use Python 3.11 or newer. The runtime has no third-party dependencies.

Install the pinned development-only linter in a disposable environment:

```sh
python3 -m pip install ruff==0.16.2
```

Run the repository checks:

```sh
python3 -m unittest discover -s tests -v
python3 -m compileall -q src skill/scripts tests
ruff check --no-cache src skill/scripts tests
```

Contract changes belong in `tests/test_contract.py`; state and routing behavior belong in their owning
test modules. Add the smallest decisive check for a changed public contract. Avoid duplicate
cross-layer assertions, broad fixture frameworks, generated bytecode, credentials, caches, or
user-specific paths in commits.

## Pull requests

Describe the observable change, owning layer, compatibility impact, and exact checks run. Keep `main`
protected by the lint check and the Linux, macOS, and Windows Python 3.11 checks. Never weaken a failed
check to make a change pass.

Security-sensitive findings should follow [SECURITY.md](SECURITY.md), not a public issue.
