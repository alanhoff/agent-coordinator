$coordinator Inside the current directory, build a lean backend-only application using Node.js
and Node's built-in `node:sqlite` library for managing a todo list.

* Node's built-in test runner
* Modular design with a clear separation of concerns.
* Native TypeScript runtime, no transpilation step.
* `npm run typecheck` script.
* `npm test` script.
* `npm run lint` script.
* `npm run format` script.
* `npm start` script.
* SQLite database must be at the path `./todos.db`.
* `GET /docs.json` must return OpenAPI 3.2 JSON.
